算法可视化工具 使用说明
========================

一、第一次使用前
1. 电脑需要安装 Python 3（免费的编程运行环境）。
2. 下载地址：https://www.python.org/downloads/
   安装时一定勾选 "Add Python to PATH"（把 Python 加入 PATH），然后一路 Next。
3. 装好后，双击本目录下的 "启动算法可视化.bat" 即可打开软件。

二、怎么用
1. 顶部选算法模板，目前共 23 个模板（按力扣经典题单挑选）：
   Python：自定义代码、二分查找、线性查找、冒泡排序、选择排序、
            插入排序、链表反转、链表删除节点、单调栈、
            两数之和 II、长度最小的子数组、每日温度、
            合并两个有序链表、环形链表、删除链表倒数第 N 个节点
   C++   ：二分查找、冒泡排序、链表反转、合并两个有序链表
   Java  ：二分查找、冒泡排序、链表反转、合并两个有序链表
2. 数组框里填数字（用空格隔开）。对链表模板，这串数字表示链表节点值。
   target 的含义随模板变化：要找的数 / 要删除的值 / 环入口下标 / 倒数第 N 个。
   合并两个链表时，在 "第二组(可选)" 里填第二个链表。
3. 点 "运行 (重置)" 开始，再点 "下一步" 一行一行执行；
   点 "自动播放" 看动画，用 "每步间隔(秒)" 调节快慢。
4. 黄色高亮的那一行 = 下一步将要执行的代码。

三、各种视图怎么看
1. 数组视图：数字画成格子，彩色箭头（l 红 / r 蓝 / mid 绿 / i 橙 /
   j 紫 / min_idx 青）指到哪个格子，就表示这个变量指向第几个元素。
   l 到 r 之间的格子会整体高亮，表示当前搜索/窗口范围。
2. 链表视图：每个节点画成一个盒子，盒子之间的箭头 = next 指针。
   节点上方的彩色箭头表示 head / cur / prev / nxt / slow / fast 等
   指针指向哪个节点。断开的节点和 None 会在下方列出，
   这样"链接"和"取消链接"的过程一目了然。
   合并链表时上下两行分别画两个链表；环形链表会用红色箭头画出
   尾巴指回环入口的位置。
3. 单调栈视图：上半部分画数组，下半部分垂直画栈，栈顶标蓝并写着"栈顶"，
   入栈、出栈（pop）都能直观看到。

四、Python 代码：真正执行
1. 代码可以直接在右侧编辑框里改，改完立刻生效。
2. 数组类模板必须定义 def solve(nums, target): 函数。
   链表类模板必须定义 def solve(head, target): 函数（合并链表是
   solve(head, head2)），代码里可以直接使用 ListNode 和构建好的 head。
3. 指针变量名请用常见名字：l、r、mid、i、j、min_idx、
   head、cur、prev、nxt、slow、fast 等，这样软件才能识别成指针画出来。
4. 运行期间代码会临时锁定，结束后恢复。
5. 自定义代码：点 "新建自定义代码" 按钮，或选模板 "Python - 自定义代码"，
   把 solve 改成你自己的算法即可运行。软件会根据 solve 的参数自动识别：
      solve(nums, target) / solve(nums)  -> 数组视图
      solve(head, target) / solve(head)  -> 链表视图（无需自己定义
                                            ListNode，会自动注入）
      solve(head, head2)                 -> 合并两个链表视图
6. 任意代码模式：如果代码里没有定义 solve，软件会把整个文件当作主程序
   逐步执行——顶层语句和文件里定义的函数都会一行一行高亮。
   可直接使用 nums、target、nums2 变量；写链表时可用
   head = build_list(nums)（ListNode 和 build_list 会自动注入）。

五、C++ / Java 代码：模拟模式
1. C++ / Java 目前是模拟模式：不真正编译运行，而是按内置的算法
   逻辑一步一步演示，同样能看到数组/链表变化和指针移动。
2. 模拟模式下，修改代码文本不会改变演示步骤（改代码会在运行时提示）。
3. 等电脑装好编译器（C++ 装 MinGW，Java 装 JDK）后，以后可以升级成
   真执行模式。

六、打开自己的代码文件
点 "打开文件..." 选择 .py / .cpp / .java 文件后，软件会显示并停留在
你打开的文件，不会跳回默认示例。注意：从文件打开的代码按 Python 规则
执行。定义 solve 函数则逐步执行该函数（按参数自动识别数组 / 链表 /
合并链表视图）；没有 solve 则逐步执行整个文件。

七、常见问题
Q: 双击 bat 一闪而过 / 提示找不到 python？
A: 没装 Python，或安装时没勾选 "Add Python to PATH"。重装并勾选即可。

Q: 点运行报错 "代码编译失败"？
A: 代码有语法错误，检查括号、缩进、冒号等。

Q: 任意代码模式下想画数组 / 链表但看不到？
A: 数组变量请用 nums 或常见名字（arr、a、lst 等）；链表请用
   head = build_list(nums) 构建，ListNode 和 build_list 会自动注入。

Q: 数组输入报错？
A: 数组必须是用空格隔开的整数，例如：1 3 5 7 9
